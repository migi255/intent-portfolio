# Adaptive UI composition

- Put layout selection in the planner and choose only registered block types. Validate block types and references before rendering.
- Choose structures that serve the selected goal. Use cards for discovery, comparative rows and chronology for evaluation, and decisions and tradeoffs for technical inspection.
- Use canonical goals and validated filters in shareable URLs. Keep raw queries in memory, preserve Back and Forward behavior, and move focus to the result heading after deliberate transitions.
- Show real stage outputs in the inspector. Test invalid plans, empty states, narrow layouts, and keyboard operation.
